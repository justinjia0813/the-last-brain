# 0.2.0 — 自适应聊天与更方便的模型配置

- 重做聊天工作区：宽面板显示对话历史，窄面板可折叠历史；对话内容独立滚动，输入框始终可用。
- 跟随 Obsidian 深色和浅色主题。
- 新增模型配置窗口，支持常用服务地址预填、密钥显示切换、输入校验和真实连接测试。
- 记忆草稿可编辑后保存或确认，确认后才用于后续问答。
- 支持停止等待并丢弃迟到回答；服务端可能仍在处理或计费。
- 保留 0.1.0 的对话、记忆、配置及只读限制。

连接测试仅发送固定测试问候，不发送笔记；可能产生所选服务的调用费用。聊天仍以纯文本整段返回。Markdown 笔记检索范围、读取上限不变。移动端和真实付费模型未在本次发布中验证。

升级时只替换 main.js、manifest.json 和 styles.css，请保留原有 data.json。
