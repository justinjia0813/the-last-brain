- 使用已安装的 macOS Obsidian，启动独立用户配置及合成测试 vault；未改动真实笔记库。
- 加载真实插件构建产物，打开原生聊天视图和设置面板。
- 未同意发送上下文时，没有模型请求，输入问题仍保留。
- 允许后完成本地模拟模型问答，排除目录未被读取、未被发送。

- 来源按钮打开现存笔记；不存在的来源不会创建笔记。

- 模拟本地保存失败时不调用模型；恢复保存后可重试。
- 插件卸载并重新加载后，从数据文件恢复对话和确认记忆。
- 删除记忆与对话的原生确认窗口可用。

测试截图保存在 `output/playwright/obsidian-chat.png` 和 `output/playwright/obsidian-memory.png`，其中回答是明确的测试文本。

## 未据此证明

- 未使用用户的真实模型密钥，未调用真实付费模型，因此不同供应商的兼容性和实际回答质量仍需接入后验证。
- 未在真实大型笔记库做性能基准；当前 1 MB 单文件、20 MB 每次读取是明确的首版上限。
- 未测试移动端、不同社区主题与云端同步冲突；不要把本次桌面测试等同于所有平台兼容性。

## 复现原生检查

在项目的 `test-runtime/vault` 放置合成笔记 `research/电池.md`、`research/markets.md`、`private/秘密.md`，在独立 Obsidian 进程中打开该库，开启本机调试端口 19223。脚本会验证库路径，拒绝在别的库中运行。它会清空该测试库中插件的历史，因此不得将真实数据放入该目录。

```sh
PLAYWRIGHT_MODULE=/绝对路径/playwright node tests/obsidian-smoke.cjs
```

脚本创建临时本地模型服务，结束时关闭服务；不需要模型密钥。
