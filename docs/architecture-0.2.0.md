# 0.2.0 接口与验收约定

## 目标

将已确认的聊天工作区原型接入原生 Obsidian 插件。宽面板显示历史与对话，窄面板折叠历史；输入框固定，内容独立滚动。使用 Obsidian 主题变量保留深浅主题。提供常用模型服务配置、连接测试和可编辑的记忆审阅。

## 接口及依赖

- ChatView 仅调用 ChatHost；新增 openModelSettings、updateMemory 和 stop。历史、来源、设置仍由插件主类管理。
- ModelSettingsModal 接收 app、data、save、refresh。表单草稿独立；用户保存后才提交设置及密钥。连接测试仅发送固定测试问候，不读取笔记。
- updateMemory 校验内容，保存失败恢复数据并抛错，视图保留用户编辑内容。确认后的记忆才会参与后续问答。
- stop 标记当前任务失效，结束网络等待，忽略迟到响应。持久化进行时先完成持久化，避免新任务与旧保存交错。不承诺取消模型服务端处理。
- 继续使用原有检索、请求构造、SecretStorage 和版本 1 数据结构；无运行时依赖增加。

## 发布验收

1. 旧版对话、记忆、模型配置可重新加载，且不重置已保存数据。
2. 320 像素窄面板与宽面板可操作；输入内容在刷新和切换面板时保留；深浅主题可读。
3. 连接测试只含固定测试文字；修改服务地址不自动携带旧服务密钥。错误可见，保存失败不关闭编辑。
4. 停止后迟到回答不保存，可重新提问；记忆编辑确认与失败回滚通过测试。
5. 全部核心测试与构建通过；发布下载文件与本地构建一致。
6. Workspace 更新前备份插件文件；不覆盖 data.json；更新后版本与历史一致。
